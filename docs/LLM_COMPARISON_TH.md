# การเปรียบเทียบ LLM สำหรับ Phish Radar AI

อัปเดตเมื่อ 17 กรกฎาคม 2026

## ขอบเขตของการเปรียบเทียบ

LLM ในโปรเจกต์นี้ใช้สร้างคำอธิบายภาษาไทยและคำแนะนำสั้น ๆ จากผล Rule-based/ML เท่านั้น ค่า `FinalScore`, label และการบล็อกลิงก์ต้องไม่ขึ้นกับคำตอบของ LLM

| ตัวเลือก | จุดเด่นกับงานนี้ | ข้อแลกเปลี่ยน | บทบาทที่แนะนำ |
| --- | --- | --- | --- |
| OpenAI GPT-5.6 Luna | รุ่นประหยัดสำหรับงานปริมาณมาก, รองรับ Structured Outputs และ context 1.05M | ต้องใช้อินเทอร์เน็ตและมีค่า API | ค่าเริ่มต้นสำหรับคำอธิบายสั้น |
| OpenAI GPT-5.6 Terra | สมดุลความสามารถและต้นทุน เหมาะเมื่อ Luna อธิบายกรณีซับซ้อนไม่พอ | ราคา input/output สูงกว่า Luna | ตัวเลือกยกระดับคุณภาพ |
| Ollama + Qwen3:4b | รันในเครื่องและไม่ต้องส่งข้อมูลให้ผู้ให้บริการภายนอก | ใช้ RAM/CPU/GPU ของเครื่อง และคุณภาพ/ความเร็วขึ้นกับฮาร์ดแวร์ | ค่าเริ่มต้นของโปรเจกต์และโหมด local/offline |

ข้อมูลรุ่นและราคาอ้างอิงจากหน้าอย่างเป็นทางการของ [OpenAI Models](https://developers.openai.com/api/docs/models), [GPT-5.6 Luna](https://developers.openai.com/api/docs/models/gpt-5.6-luna), [GPT-5.6 Terra](https://developers.openai.com/api/docs/models/gpt-5.6-terra) และ [Qwen3:4b บน Ollama](https://ollama.com/library/qwen3%3A4b)

## ข้อสรุปที่ใช้ในโปรเจกต์

ตั้งค่าเริ่มต้นเป็น `qwen3:4b` ผ่าน Ollama ตามแนวทาง local/privacy ของโปรเจกต์ โดยยังเก็บ `gpt-5.6-luna` เป็นตัวเลือก cloud สำหรับเปรียบเทียบ หากผล human evaluation ของ Qwen ไม่ผ่านเกณฑ์จึงค่อยทดลอง Luna หรือ Terra ด้วยชุดทดสอบเดียวกัน

ข้อสรุปนี้ยึดความต้องการให้ใช้ Qwen เป็นค่าเริ่มต้นและลดการส่งข้อมูลออกนอกเครื่อง ยังไม่ใช่ผล benchmark บนเครื่องนี้ จึงไม่ควรอ้างว่าโมเดลใดแม่นกว่ากันจนกว่าจะทดสอบด้วยชุดข้อมูลเดียวกัน

## วิธี benchmark ให้เปรียบเทียบอย่างยุติธรรม

ใช้ URL อย่างน้อย 30 กรณีที่มีทั้ง legitimate, phishing, punycode, shortener, login ปลอม และกรณีคะแนนก้ำกึ่ง ส่ง prompt และข้อมูลอินพุตชุดเดียวกันให้ทุกโมเดล แล้วบันทึก:

1. ความถูกต้องของประเภทความเสี่ยงและคำอธิบายภาษาไทย คะแนน 1–5 โดยผู้ประเมินอย่างน้อย 2 คน
2. อัตรา JSON/schema ผ่านโดยไม่ต้องซ่อม
3. อัตราการกล่าวเกินหลักฐานหรือสร้างข้อมูลขึ้นเอง
4. latency แบบ p50/p95
5. token และต้นทุนเฉลี่ยต่อคำขอสำหรับ cloud model
6. RAM/VRAM และเวลาเฉลี่ยต่อคำขอสำหรับ local model

ให้เลือกโมเดลจากคุณภาพขั้นต่ำที่กำหนดก่อน แล้วจึงพิจารณาราคาและ latency ห้ามนำผล LLM ไปเปลี่ยน label ของตัวตรวจจับระหว่างการทดลอง

## หมายเหตุด้านข้อมูล

OpenAI ระบุว่าข้อมูลจาก API ไม่ถูกใช้ฝึกโมเดลโดยค่าเริ่มต้น เว้นแต่ผู้ใช้เลือกเข้าร่วม แต่ abuse monitoring logs อาจเก็บเนื้อหาได้นานสูงสุด 30 วันตามค่าเริ่มต้น ดู [นโยบายการใช้ข้อมูล](https://openai.com/policies/how-your-data-is-used-to-improve-model-performance/) และ [API data controls](https://platform.openai.com/docs/models/default-usage-policies-by-endpoint) หากกรณีใช้งานไม่อนุญาตให้ส่งข้อมูลออกนอกเครื่อง ให้เลือก Ollama หรือเปิด Privacy Mode
