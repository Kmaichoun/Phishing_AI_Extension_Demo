# ชุดเอกสารให้เพื่อนเขียนบทความ Phish Radar

จัดเตรียมวันที่ 17 ตุลาคม 2026 ตามหัวข้อในภาพที่ได้รับจากผู้ใช้ ชุดนี้มี **โครงบทความและคู่มือให้ผู้เขียนลงมือเขียนเอง** ยังไม่ใช่บทความฉบับส่งอาจารย์

## เริ่มจากตรงนี้

1. อ่าน [ข้อเท็จจริงและหลักฐานของโครงงาน](PROJECT_FACTS_TH.md) เพื่อเข้าใจรุ่นโมเดล สูตร และขอบเขตของผลทดลอง
   อ่าน [แหล่งที่มาของ dataset](DATASET_SOURCES_TH.md) เพื่อแยกข้อมูลพัฒนา ชุดยืนยัน ผลย้อนหลัง และข้อมูลที่ทีมเก็บเพิ่ม
2. อ่าน [คู่มือเขียนแต่ละส่วน](WRITING_GUIDE_TH.md) แล้วแบ่งผู้รับผิดชอบตามหัวข้อ
3. คัดลอก [โครงบทความ](ARTICLE_OUTLINE_TH.md) ไปเป็นไฟล์ทำงาน หรือวางใน Word ตามแม่แบบของอาจารย์
4. ทำหัวข้อทฤษฎีและงานวิจัยที่เกี่ยวข้องควบคู่กับ [เอกสารอ้างอิง](REFERENCES_TH.md) ตั้งแต่เริ่ม
5. เติมภาพระบบ ผลทดสอบ และรายละเอียดผู้จัดทำจากงานจริง ตรวจรายการก่อนส่งในคู่มือ

อ่าน Markdown บน GitHub ได้ทันที ไม่ต้องติดตั้ง Python หรือเปิดระบบเพื่อเริ่มเขียน

## สำคัญเกี่ยวกับรุ่นของโครงงาน

ข้อมูลในชุดนี้อ้างอิง source และ artifact ในเครื่องที่ตรวจวันที่ 17 ตุลาคม 2026 โดยใช้ SHA256 และไฟล์หลักฐานใน `evidence/` ระบุรุ่น ไม่ใช่ผลทดสอบใหม่ในวันนี้ และไม่ได้ยืนยันว่าเซิร์ฟเวอร์ใดกำลังโหลดรุ่นนี้

branch เอกสารนี้ต่อจาก commit `c875719792321a2ca4e4d057e037b7c253522d39` ของ repository เดิม ซึ่งเป็น source ที่เก่ากว่าสำเนาในเครื่องที่ใช้ตรวจข้อเท็จจริง **การอัปโหลดครั้งนี้เพิ่มชุดเอกสารเท่านั้น** source และ `backend/model.pkl` ที่ฐานของ branch จึงอาจไม่ตรงกับรุ่นที่บันทึกในชุดนี้ อย่าใช้ source เก่าพิสูจน์ผลของโมเดลใหม่ หากจะรันทดลองซ้ำ ให้รับ source และ artifact ที่มี hash ตรงกับหลักฐานจากเจ้าของโครงงานก่อน

เอกสารเดิมใน repository บางฉบับอธิบายสูตรหลายยุค เช่น learned fusion หรือเกณฑ์เดิม ให้เริ่มจาก `PROJECT_FACTS_TH.md` เมื่อเขียนถึงรุ่นที่ตรวจครั้งนี้

## งานที่ยังเป็นหน้าที่ผู้เขียน

- เติมชื่อบทความ ผู้เขียน สังกัด อาจารย์ และรายวิชาตามข้อมูลจริง
- เขียนเนื้อหาด้วยภาษาของตนเอง พร้อมอ้างอิงในตำแหน่งที่ใช้ข้อมูล
- เลือกว่าจะรายงานผลการทดลองรอบใด แล้วใช้ชื่อรุ่น ชุดข้อมูล เกณฑ์ และข้อจำกัดให้ตรงกันตลอดทั้งเรื่อง
- เก็บภาพหน้าจอและหลักฐานการใช้งานรอบที่จะนำเสนอ ตรวจว่าไม่มีข้อมูลส่วนบุคคลติดภาพ
- จัดหน้าและตรวจความครบถ้วนตามแม่แบบของอาจารย์
