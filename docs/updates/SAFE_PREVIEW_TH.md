# Safe Preview Update

เพิ่มฟีเจอร์ Safe Preview เพื่อให้ผู้ใช้ดูเว็บเสี่ยงก่อนตัดสินใจ โดยยังไม่เปิดโอกาสให้กรอกข้อมูลสำคัญ

## การทำงาน

1. หน้า Warning มีปุ่ม "เปิด Safe Preview"
2. เมื่อกด ระบบจะเปิดเว็บปลายทางในแท็บเดิม แต่เข้าสู่โหมด Safe Preview
3. Extension จะ inject ชั้นป้องกันเข้าไปบนหน้าเว็บ
4. ช่องข้อมูลสำคัญจะถูกล็อก เช่น password, OTP, token, PIN, ข้อมูลบัตร, seed phrase, recovery phrase และ private key
5. การ submit form จะถูกบล็อก
6. ผู้ใช้สามารถกลับหน้าเตือน หรือเลือกเปิดแบบเต็มหลังยืนยันความเสี่ยงเอง

## จุดเด่น

- ใช้งานได้จริงกว่าการบล็อกอย่างเดียว
- ผู้ใช้ยังดูหน้าตาเว็บได้ แต่ลดโอกาสเผลอกรอกข้อมูลลับ
- ไม่ใช้ LLM และไม่กิน token
- ต่อกับหน้า Warning เดิมได้ทันที

## วิธีทดสอบ

1. Reload extension ที่ chrome://extensions
2. เปิดลิงก์ที่ถูกเตือนจนเข้าหน้า Warning
3. กด "เปิด Safe Preview"
4. ลองคลิก/พิมพ์ในช่อง password หรือกด submit ระบบควรบล็อกไว้
