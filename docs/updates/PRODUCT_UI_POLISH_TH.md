# Product UI Polish Update

ปรับ UI ให้ดูเป็นเครื่องมือจริงมากขึ้น โดยเน้นลดความรกและลดความรู้สึกเหมือน debug/demo

## สิ่งที่ปรับ

1. Popup เปลี่ยนเป็น light product UI
   - สีพื้นอ่านง่ายขึ้น
   - card และปุ่มใช้ radius น้อยลง ดูเป็นเครื่องมือจริงมากขึ้น
   - ปุ่มหลักเหลือ "ตรวจหน้านี้" และ "เชื่อถือเว็บนี้"

2. ย้ายฟีเจอร์รองไปไว้ใน "เครื่องมือเพิ่มเติม"
   - หน้า Demo
   - เว็บจำลอง
   - ทดสอบ URL เอง
   - ตั้งค่า threshold และ toggle ต่าง ๆ

3. ลด alert popup
   - เปลี่ยนผลลัพธ์การสแกน/whitelist เป็นข้อความสถานะใน popup

4. หน้า warning page ลดความเป็น demo
   - เปลี่ยนข้อความหัวเตือนให้ดูเป็น product
   - ปรับ radius และพื้นหลังให้สงบขึ้น

## วิธีทดสอบ

1. Reload extension ที่ chrome://extensions
2. กดไอคอน Phish Radar AI
3. ตรวจว่า popup ดูสะอาดขึ้น และกด "เครื่องมือเพิ่มเติม" เพื่อเปิดฟีเจอร์รอง
